# FRANK Resume Builder

Professional, frontend-only resume builder.

### Features
- Live resume preview
- Modern / Minimal / Executive templates
- Personal details, summary, experience, education, skills, projects, certifications, languages
- Photo upload
- Accent color customization
- LocalStorage auto-save
- Resume strength meter
- Responsive mobile layout
- Print / Save as PDF
- No backend, server, database or API required

### Hosting
Upload the complete folder to GitHub Pages, Netlify, Vercel static hosting, or any static host.
Open `index.html` locally to test.
